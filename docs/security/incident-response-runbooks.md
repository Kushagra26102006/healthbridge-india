# HealthBridge India — Security Incident Response Runbooks (Day 9 Task 04)

> **Regulatory Reporting Notice:** External notification obligations (e.g., to CERT-In, the Data Protection Board of India under DPDP Act/Rules, NHA/ABDM, or affected Data Principals) depend on verified legal applicability and live notified timelines. **Do NOT rely on assumed deadlines** — engage designated legal counsel & Privacy Officer immediately upon any confirmed SEV-1 / data exposure incident.

---

## Runbook Summary Matrix (All 12 Required Scenarios)

| # | Scenario | Severity | Primary Detection Signals | Immediate Containment (`SECURITY_INCIDENTS_RESPOND`) | Evidence Preservation | Recovery & Post-Incident |
|---|---|---|---|---|---|---|
| **1** | **Patient Account Compromise** | HIGH | `RULE_REFRESH_TOKEN_REUSE`, `RULE_REPEATED_FAILED_LOGINS_ACCOUNT`, unexpected export/consent grants | Revoke all user refresh tokens (`revokeAllUserSessions`), lock account status, revoke suspicious consents via `invalidateConsentImmediately`. | Snapshot `securityEvents`, `auditLogs`, `dataAccessEvents`, `privacyRequests` for user. | Force verified password reset, audit unauthorized exports/consents, notify patient neutrally, complete blameless RCA. |
| **2** | **Doctor Account Compromise** | CRITICAL | `RULE_CROSS_PATIENT_ACCESS_PATTERN`, anomalous bulk patient/prescription activity | Suspend doctor account, revoke all sessions, halt pending prescription/encounter writes, review active consents held by clinician. | Preserve clinician `auditLogs`, `dataAccessEvents`, prescriptions issued during compromise window. | Re-verify HPR identity & credentials, notify affected clinic/patients per legal counsel, review clinical integrity. |
| **3** | **Administrator Account Compromise** | CRITICAL | Unexpected `ROLE_PERMISSION_CHANGE`, unauthorized SecOps or legal-hold modifications | Immediately suspend admin account, revoke all sessions, rotate `JWT_ACCESS_SECRET` / `JWT_REFRESH_SECRET` if secret exposure suspected, freeze admin write ops. | Export immutable `auditLogs`, `adminProfiles` changes, `securityIncidents` timelines to WORM storage. | Audit every admin action during window, restore clean permission baseline, engage legal/executive stakeholders. |
| **4** | **Unauthorized Patient Record Access** | CRITICAL | `RULE_CROSS_PATIENT_ACCESS_PATTERN`, `OWNERSHIP_VIOLATION`, `CONSENT_ACCESS_DENIED` spikes | Suspend offending actor, verify `ConsentEnforcementService` revocation barrier, patch broken ownership/RBAC rule if vulnerability confirmed. | Export `dataAccessEvents` & `auditLogs` showing exact `resourceCategory` and `ALLOWED` vs `DENIED` outcomes. | Validate isolation tests, engage Privacy Officer & legal counsel on patient/regulator notice obligations. |
| **5** | **Suspected Data Exposure / Exfiltration** | CRITICAL | `BULK_DATA_ACCESS_ATTEMPT`, unexpected export spikes, external leak report | Revoke compromised credentials/tokens, invalidate active signed export/document URLs, isolate affected API/storage paths. | Preserve access logs, network/WAF logs, SHA-256 export manifests without altering source collections. | Determine exact scope (fields/count), execute legal counsel breach notification workflow, harden egress controls. |
| **6** | **Malware Upload Incident** | HIGH | `MALWARE_SCAN_ALERT` (`INFECTED`), `FILE_SIGNATURE_REJECTED` burst | Confirm file held in `INFECTED` quarantine (`SecureDocumentStorageService` blocks download), suspend abusive uploader if malicious. | Retain metadata (`sha256IntegrityHash`, `storageId`, uploader ID, requestId); isolate infected object. | Verify zero downloads occurred prior to quarantine, purge infected object after forensic clearance, review upload filters. |
| **7** | **Encryption Key Compromise** | CRITICAL | Unexpected `KEY_ROTATION_EVENT`, anomalous `DECRYPTION_FAILURE` or KMS IAM alert | Trigger `keyManagementService.rotateKey()`, revoke compromised IAM principal, run priority `KeyRotationOrchestrator` batch re-encryption. | Capture KMS audit trail, key version metadata, and decryption logs for compromise window. | Confirm zero active records reference compromised `keyId`, follow legal counsel breach assessment. |
| **8** | **Database Compromise** | CRITICAL | Unusual Atlas access, `NOSQL_INJECTION_BLOCKED` spikes, unauthorized IP/user connection | Rotate `MONGODB_URI` credentials, lock down Atlas IP allow-list/VPC peering, isolate affected API nodes, rotate JWT/cookie secrets. | Preserve Atlas audit logs and point-in-time snapshot before remediation. | Restore clean verified snapshot if tampered, run `reconcileRestoredDataset()`, complete legal breach assessment. |
| **9** | **ABDM Integration Compromise** | CRITICAL | `RULE_INTEGRATION_REPLAY_ABUSE`, `ABDM_CALLBACK_VALIDATION_FAILURE`, forged HIU/HIP traffic | Set `ABDM_ENABLED=false` circuit breaker, rotate `ABDM_CLIENT_SECRET` & `ABDM_WEBHOOK_SECRET`, quarantine unverified imported records. | Preserve `abdmWebhookEvents`, callback signatures, consent artefacts, and transfer logs. | Coordinate with NHA ABDM technical support/CERT-In per legal counsel, re-verify webhook signatures before re-enabling. |
| **10** | **Backup Failure** | HIGH | `RESTORE_FAILURE`, missed Atlas backup alert, checksum mismatch | Halt destructive maintenance, trigger manual verified backup snapshot, check Atlas storage/KMS IAM permissions. | Record failed job logs and `BackupMetadataRecord` diagnostics. | Execute isolated staging restore drill (`database-restore-runbook.md`), confirm `reconcileRestoredDataset()` passes. |
| **11** | **Event-Processing Abuse / Poison Flood** | HIGH | `EVENT_REPLAY_ATTEMPT`, abnormal `/api/v1/events/dead-letter` growth | Pause non-critical outbox workers, verify idempotency keys blocked duplicate side effects, isolate abusive source module. | Snapshot `outboxEvents` & `deadLetterEvents` without exposing PHI. | Fix faulty producer/handler, selectively replay verified legitimate events via `ADMIN` console. |
| **12** | **API Denial-of-Service (DoS) Incident** | HIGH | `RULE_API_ABUSE_PATTERN`, `RATE_LIMIT_EXCEEDED` storm, elevated API latency | Tighten edge WAF / CDN IP throttling, raise rate-limit strictness on abusive routes, protect clinical endpoints first. | Retain edge access logs, offending IP/ASN clusters, and request rate graphs. | Gradually relax emergency throttling once traffic normalizes, update WAF/Redis rate-limit rules in RCA. |
